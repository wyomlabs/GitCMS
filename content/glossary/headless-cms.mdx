## When it fits

A headless CMS shines for multi-channel content, deeply relational models, and real-time collaboration.

## The cost on a code-first site

Content behind an API is a second source of truth. Coding agents can't see it in the repository, Git history doesn't record it, and every page must fetch it. For marketing sites and blogs, that's often more machinery than the content needs.
