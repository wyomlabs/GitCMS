## Why they existed

Builders traded ownership, performance, and flexibility for one thing: non-developers could build and run the site. When code was slow and expensive, that was a good trade.

## What changed

Coding agents made code the fastest way to build. The part of the builder most teams still need is the admin: editing, publishing, and review. A code-first site with a CMS like GitCMS keeps the code and adds that admin. Read the [manifesto](/manifesto) for the full argument.
