## Examples

Website builders like Wix, Squarespace, Webflow, and Framer are no-code tools for websites. You pick a template, drag sections around, and publish to the platform's hosting.

## Strengths

- Anyone can build and edit
- Hosting, forms, and CMS come bundled
- No deployment or code review to think about

## Limits

You build inside the platform's model. Custom behavior, performance tuning, portability, and version control are limited, and moving away usually means rebuilding.

## No-code vs code in 2026

No-code existed because code was slow and expensive to write. AI coding agents changed that: describing a site to Claude Code now produces real, ownable code faster than assembling it in a builder. What no-code still does better is the **admin**: a place for non-developers to run the site. That's the gap a [code-first website](/glossary/code-first-website) fills with a CMS.
