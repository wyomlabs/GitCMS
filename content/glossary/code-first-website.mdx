## Why it matters

For years, building a custom site in code was slow and expensive, so most teams chose a website builder like WordPress, Webflow, or Framer instead. Coding agents changed that. Claude Code, Codex, and Cursor can build a custom site in hours, which makes code the fastest way to get a website live, not the slowest.

A code-first site is fast, fully owned, portable across hosts, and easy for agents to keep improving. Every change has a commit, an author, and a diff.

## What it doesn't come with

A codebase doesn't include an admin. Clients and marketers can't change copy or publish posts without a developer, and changes made by AI agents have no review step unless you add one. That gap is [Day Two](/glossary/day-two).

## In GitCMS

GitCMS is the CMS for code-first and AI-built websites. It connects to the repository and gives your team, clients, and AI agents one safe place to edit, review, and publish, while the website stays code.
