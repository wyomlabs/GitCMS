## Example

```md
# Opening hours

We're open **Monday to Friday**, 8am to 6pm.

- Emergency call-outs 24/7
- [Book online](/book)
```

John Gruber created Markdown in 2004. Today most tools follow the CommonMark specification, often with GitHub-flavored extensions such as tables.

## Why websites use it

- Readable as plain text, so diffs and reviews make sense
- Portable across frameworks and tools
- Easy for static site generators to turn into pages

## Why agents like it

Markdown is close to how language models already write. An agent can read, edit, and review a Markdown file without an API or special format.

## For non-developers

Clients and marketers shouldn't have to type Markdown. A CMS can show it as a visual editor and save it back as Markdown, which is what GitCMS does.
