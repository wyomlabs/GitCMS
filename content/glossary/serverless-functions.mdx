## What websites use them for

- Contact and lead forms
- Newsletter sign-ups
- Search and API proxies
- Server-rendered or personalized routes
- Webhooks from other services

Examples include Vercel Functions, Netlify Functions, Cloudflare Workers, and AWS Lambda.

## Tradeoffs

- **Pay per use**: cheap at low traffic, but costs grow with requests
- **Cold starts**: some platforms add latency to the first request
- **Limits**: execution time, memory, and available APIs vary by platform

## The pattern

Most code-first marketing sites are static pages plus a handful of functions. You get static speed and cost for content, and server code only where it's needed.
