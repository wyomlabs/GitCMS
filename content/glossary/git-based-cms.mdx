## How it works

The site's framework reads Markdown, MDX, or data files from the repository. The CMS edits those files and commits the changes. Your host rebuilds the site from the new commit.

## Strengths and limits

Strengths: one source of truth, full history, no content API, and content that coding agents can read directly. Limits: every change triggers a build, and content that changes every second belongs in a database.
