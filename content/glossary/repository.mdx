## What's inside a website repository

```text
my-site/
├── src/            pages, components, layouts
├── src/content/    blog posts, pages, case studies (Markdown/MDX)
├── public/         images and static files
├── package.json    dependencies and scripts
└── .gitcms/        GitCMS configuration
```

Repositories are usually hosted on GitHub, GitLab, or Bitbucket, where hosts connect to them for deployment.

## The source of truth

On a code-first website, the repository is the website. Whatever is in the main branch is what gets deployed. That's why a CMS for a code-first site should write to the repository instead of keeping its own database.

## In GitCMS

GitCMS connects to GitHub repositories, reads the sites and content in them, and commits changes back. A repository can contain more than one site.
