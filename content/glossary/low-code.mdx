## How it works

Low-code platforms give you visual building blocks, then let developers drop into code for custom components, logic, or integrations. Webflow with custom code embeds, or WordPress with custom themes and plugins, sit in this space for websites.

## Where it fits

Low-code suits teams with some developer time who still want non-developers to build pages. The tradeoff is two worlds to maintain: the platform's visual model and the custom code bolted onto it.

## Low-code vs pro-code with AI

AI agents shrank the cost of the "pro-code" end. When an agent can write the custom parts and the rest, many teams skip the hybrid and go fully code-first, then add a CMS so non-developers can still edit content. Compare [no-code](/glossary/no-code) and [pro-code](/glossary/pro-code).
