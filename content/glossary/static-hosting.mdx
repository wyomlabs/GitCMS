## Providers

Cloudflare Pages, Netlify, Vercel, GitHub Pages, and Amazon S3 with CloudFront all host static files, most with free tiers that cover typical marketing sites.

## What you get

- Global CDN delivery
- Automatic HTTPS
- Deploys from Git on every commit
- Preview URLs for branches (on most providers)

## When you need more

Forms, search, logins, and personalization need some server-side code. Most static hosts add [serverless functions](/glossary/serverless-functions) for that, so you rarely need to leave static hosting entirely.

## Compared to WordPress hosting

There's no PHP, database, or plugin stack to patch, and hosting costs drop from monthly server fees to often nothing.
