## A typical website pipeline

| Stage | Example checks |
|---|---|
| Integration | Type-check, lint, unit tests |
| Build | Render pages, validate content |
| Checks | Broken links, accessibility, bundle size |
| Delivery | Deploy a preview, then production on merge |

Tools include GitHub Actions, GitLab CI, and the built-in pipelines of hosts like Vercel and Netlify.

## Content goes through it too

On a code-first site, a content commit runs the same pipeline as a code commit. That's a feature: broken content is caught before it ships. It also means content edits need to produce valid files every time, which a structured editor helps guarantee.
