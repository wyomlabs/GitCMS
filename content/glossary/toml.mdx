## Example

```toml
title = "Emergency plumbing in Austin"
draft = false

[hours]
weekdays = "8am-6pm"
weekends = "closed"
```

TOML stands for Tom's Obvious, Minimal Language.

## Where you'll see it

- **Hugo** and **Zola** configuration, and frontmatter between `+++` fences
- Rust's `Cargo.toml`, Python's `pyproject.toml`
- Many CLI tool configs

## Why people like it

TOML avoids YAML's indentation traps and JSON's quoting and comma rules. Types are explicit, and comments are allowed.

## In GitCMS

GitCMS supports YAML, TOML, and JSON frontmatter. Set the format to match your site so edits keep the same style.
