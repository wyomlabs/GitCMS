## What it does

Git tracks changes to files over time. Every saved change is a commit with an author, a timestamp, and a description. You can compare versions, work on changes in parallel with branches, and roll back mistakes.

## Why websites are built on it

- The website's code and content live together in one [repository](/glossary/repository)
- Hosts like Vercel, Netlify, and Cloudflare deploy automatically from Git
- Every change, from a developer, a client, or an AI agent, is recorded and reversible
- Coding agents work directly with Git repositories

## Git for content

Git wasn't designed for marketers, but its guarantees are exactly what content needs: history, review, and rollback. A [Git-based CMS](/glossary/git-based-cms) gives non-developers those guarantees without the command line. GitCMS is built on this idea: every save is a real Git commit.
