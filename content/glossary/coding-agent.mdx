## How they changed websites

Coding agents made code the fastest way to build a website. They also keep working after launch: refactoring, adding sections, and generating pages.

## Coding agents and content

For code changes, the usual review path is a pull request. For content changes, which marketers and clients care about, a CMS workflow fits better. Coding agents can also set up GitCMS on a repository with a copy-paste prompt and connect to GitCMS through MCP for content work.
