## How it works

The server returns a small HTML shell and a JavaScript bundle. The browser downloads and runs the JavaScript, fetches data, and renders the page. Classic single-page apps built with React and Vite work this way.

## Tradeoffs

- **Slower first view**: nothing meaningful shows until JavaScript loads and runs
- **SEO and AI crawlers**: many crawlers, including some AI answer engines, read little or nothing from a page that needs JavaScript to render content
- **Great for apps**: once loaded, navigation and interactions feel instant

## For websites

Content pages, such as marketing pages, blogs, and docs, should be pre-rendered or server-rendered so search engines and answer engines can read them. Keep CSR for app-like areas behind a login.
