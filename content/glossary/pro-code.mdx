## What it looks like for websites

A pro-code website is a project in a framework like Astro, Next.js, or Hugo, stored in a Git repository and deployed to a host like Vercel, Netlify, or Cloudflare. Everything is code you own.

## Why it used to be expensive

Pro-code meant paying developers for every page, section, and change. That's why most small businesses and marketing teams chose builders.

## What changed

Coding agents write most of the code now. Designers, growth teams, and agencies build pro-code sites by describing them, which makes pro-code the fast option instead of the slow one.

## What it still needs

A pro-code site has no admin out of the box. Clients and marketers need a way to edit content, and agent changes need review. That's [Day Two](/glossary/day-two), and it's what GitCMS adds.
