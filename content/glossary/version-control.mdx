## Version control vs revision history

Many CMSs keep revisions of individual pages. Version control goes further: it tracks every file in the project together, so one change can span content, images, and code, and can be reviewed and reverted as a unit.

| | CMS revisions | Version control (Git) |
|---|---|---|
| Scope | One entry at a time | The whole project |
| Review before publish | Plugin or plan-dependent | Built in (branches) |
| Who can audit it | CMS admins | Anyone with repo access |
| Portability | Locked in the CMS | Standard Git history |

## Why it matters now

When AI agents edit websites, version control is how you see exactly what an agent changed and undo it. That's a large part of why code-first websites are a good fit for agent-maintained content.
