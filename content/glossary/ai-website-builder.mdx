## Two kinds

| Kind | Examples | Where the site lives |
|---|---|---|
| Platform builders with AI | Webflow, Framer, Wix | In the platform |
| App and site generators | Lovable, Bolt, v0 | As code, often synced to GitHub |

Coding agents like Claude Code, Codex, and Cursor are a third route: they work in a repository you already own.

## What to check before choosing

- Can you export or sync the code to your own repository?
- Where does editable content live: in components, or in content files?
- How will non-developers edit the site after launch?

## After generation

Generated sites tend to hardcode copy in components. If the site lives in Git, move editable text into content files and connect a CMS so the people who run the site don't need the builder, or the prompt, for every change.
