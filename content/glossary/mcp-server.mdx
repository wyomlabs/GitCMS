## Why it matters

Before MCP, every AI tool needed custom integrations. With MCP, a product exposes one server, and any compatible agent can connect, authenticate, and call its tools.

## The GitCMS MCP server

GitCMS runs an MCP server at `https://mcp.gitcms.dev`. Connected agents can list your sites and collections, read entries, create content tasks, write and edit drafts, and submit them for review. In ChatGPT and Claude, GitCMS can open its visual editor inside the chat.

Agents get structured access to content, not your repository credentials. See [AI agents](/agents) for setup by agent.
