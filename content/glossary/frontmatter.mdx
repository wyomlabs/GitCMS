## Example

```md
---
title: Emergency plumbing in Austin
heroHeadline: Licensed plumbers in under an hour
pubDate: 2026-10-10
---
```

## Why it matters

Frameworks read frontmatter to render titles, dates, SEO tags, and page sections. Field names must match what the code expects.

## In GitCMS

GitCMS shows frontmatter as labeled form fields, so editors never see YAML. It supports YAML, TOML, and JSON frontmatter.
