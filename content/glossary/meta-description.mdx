## Example

```html
<meta name="description" content="Licensed Austin plumbers, at your door in under an hour. Upfront quotes, 24/7 emergency call-outs." />
```

## Writing a good one

- Aim for roughly 140–160 characters so it isn't cut off
- Say what the reader gets, not just what the page is
- Use the words people search for, naturally
- Write a unique one for every page

Search engines rewrite descriptions they consider unhelpful, so a good description is a suggestion, not a guarantee.

## On code-first sites

The description usually lives in a page's [frontmatter](/glossary/frontmatter) as a `description` field that the layout renders into the head. That makes it an easy bulk task for an agent: check every entry, fix missing or weak descriptions, and submit them for review.
