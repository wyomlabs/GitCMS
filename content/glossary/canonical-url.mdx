## Example

```html
<link rel="canonical" href="https://example.com/pricing/" />
```

## Duplicates it solves

- With and without a trailing slash: `/pricing` and `/pricing/`
- Tracking parameters: `/pricing?utm_source=x`
- `http` vs `https`, `www` vs bare domain
- The same post syndicated to another site

Without a canonical, search engines split ranking signals across the versions, or pick one you didn't intend.

## Common mistakes

- Canonical points to a URL that redirects
- Sitemap lists one version, canonical names another
- Every page's canonical points to the homepage

Keep internal links, the sitemap, and canonicals all using the same form of each URL.
