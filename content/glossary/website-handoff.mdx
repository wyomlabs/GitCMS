## Why handoffs fail

Most handoffs hand over a login and a hope. With builder sites, the client got an admin. With code-first sites built by agents, there's often nothing to hand over except the repository, so every small change comes back to the builder.

## What a good handoff includes

- Editable content separated from code (content files, not hardcoded copy)
- An editor the client can use without Git
- Access scoped to the client's site only
- A clear split: the client owns copy and posts, the builder owns design and features
- A review step when the builder needs to approve changes
