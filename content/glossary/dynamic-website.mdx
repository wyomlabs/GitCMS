## How it works

When a visitor requests a page, server code runs, queries data, and assembles the HTML. WordPress, Drupal, and most web apps work this way. Caching often makes them behave partly like static sites.

## When you need it

- Content is personalized per visitor or per account
- Data changes every few seconds (inventory, live scores)
- The site is really an application: logins, dashboards, checkout

## The costs

A server and usually a database to run, update, secure, and scale. For marketing sites whose content changes a few times a week, that's often more infrastructure than the job needs.
