## Example

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Austin Plumbing Co.",
  "url": "https://example.com",
  "logo": "https://example.com/logo.png"
}
</script>
```

## Types worth using on marketing sites

| Type | Use it for |
|---|---|
| `Organization` | Your company, on every page |
| `SoftwareApplication` / `Product` | What you sell, with offers |
| `Article` / `BlogPosting` | Blog posts and guides |
| `FAQPage` | Question-and-answer sections |
| `LocalBusiness` | Local service businesses |
| `DefinedTerm` | Glossary entries |

## Why it matters

Structured data can enable rich results in Google and gives answer engines unambiguous facts about your entity. It doesn't replace good content, but it removes guesswork.

## On code-first sites

Generate JSON-LD from the same data your page renders (frontmatter fields, FAQ lists), so the two can't drift apart.
