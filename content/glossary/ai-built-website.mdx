## How they're built

A person describes the site, and a coding agent writes the components, pages, and styles in a framework like Astro or Next.js. The person reviews, asks for changes, and deploys. Agencies report that sites which took a week now ship in a day or two.

## What happens after launch

The build is the easy part now. After launch, the client needs to change opening hours, marketing needs to publish a case study, and the agent will keep proposing edits. Those changes need an editor for non-developers and a review step for agents. Without one, whoever built the site becomes its permanent content operator.

## In GitCMS

GitCMS connects to the repository behind an AI-built site. Clients and marketers edit visually, agents draft changes through MCP inside content tasks, and people approve what gets published. See [how to hand off a Claude Code website to a client](/blog/hand-off-claude-code-website-to-client).
