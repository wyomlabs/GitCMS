## v0.0.1 — Where It Started

GitCMS didn't start as a product. It started as something I built for myself because I was tired of editing Markdown in GitHub's plain textarea.

The idea was simple: what if GitHub's file editor felt like Notion? So I built a [Chrome extension](https://chromewebstore.google.com/detail/pemglpclheejlbobifgdbjjofdhmiafm?utm_source=item-share-cb) that replaced GitHub's default editor with a visual block editor — same concept as today, just embedded directly into GitHub's UI.

No workspaces, no collections, no settings. Just open a `.md` file on GitHub, get a better editor, save it as a commit.

It was rough. It was limited. But it worked well enough that I kept using it — and eventually started thinking it deserved to be something more.

That's when GitCMS became a proper web app.
