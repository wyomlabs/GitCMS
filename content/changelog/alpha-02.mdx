## Alpha Update 02

GitCMS is now a proper GitHub-connected product.

GitCMS now moves beyond a single editing surface into an app with authentication, connected repositories, onboarding, workspaces, and early team collaboration primitives.

## What changed

- Added GitHub authentication and app-based repository access
- Added repository onboarding and setup flow
- Added workspaces to organize sites and repositories
- Added team invitations and member management
- Added route and layout foundations for the full app shell

## Why it mattered

GitCMS is now usable as a product instead of a personal tool. A repo can be connected, configured, and shared through one app, which lays the groundwork for collaboration and site management.
