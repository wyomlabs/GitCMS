## What you can do now

**Edit content like Notion, commit to Git automatically**

Write with slash commands, drag-and-drop blocks, and rich formatting. Behind the scenes, every save creates a real Git commit with full history. No manual file editing, no YAML syntax errors.

**Manage multiple sites from one monorepo**

One repo can now host multiple independent websites. GitCMS manages site discovery through `.gitcms/sites.jsonc` and lets you switch between sites. Perfect for docs + blog + marketing in the same repository.

**Let AI edit your content**

ChatGPT and Claude can now read and write your content through the Model Context Protocol. Ask the AI to update a blog post, create a new page, or submit a draft for review—it commits directly to your repo.

**Work with your favorite framework**

GitCMS supports Astro, TanStack Start, Next.js, Hugo, Jekyll, Gatsby, Eleventy, Nuxt, SvelteKit, Docusaurus, VuePress, and MkDocs. Auto-detection sets up the right paths based on your config files.

**Editorial workflow on a content board**

Move cards through a content board (Ideas → Draft → Review → Published) without managing branches or pull requests. Writers and reviewers work in familiar editorial vocabulary while Git handles versioning underneath.

**Own it, don't rent it**

$49 per site, $9 per seat—one-time during launch. No subscriptions, no recurring costs. You can preview your site in GitCMS before you buy a license.
