title: Licensing & Preview
description: Understand preview mode, site licenses, MCP access, and complimentary access in GitCMS.
---

GitCMS lets you connect a repository, initialize `.gitcms`, and explore your website before you buy a license.

## Preview mode

Preview mode is for trying GitCMS on a real website before purchasing access.

In preview mode, you can:

- Connect a repository
- Set up `.gitcms`
- Open the website in GitCMS
- Browse collections, content, and settings
- Explore the editor UI

In preview mode, you cannot:

- Save changes to GitHub
- Publish content
- Use MCP
- Use other write actions that change remote state

## Site licenses

GitCMS is licensed per website.

- **Site license:** $79 one-time per website during launch
- **Extra seats:** $9 per additional seat

Once a website is licensed, saving, publishing, MCP access, and role-based team workflows are unlocked for that site.

That includes:

- inviting teammates or collaborators
- assigning editor, reviewer, or viewer access
- limiting members to selected sites
- granting publish access only when needed

## MCP access

MCP is only available for licensed websites.

If a website is still in preview mode, you can explore it in the web app, but MCP stays locked until that website has a license.

## Personal sites and OSS

If you run a personal site or OSS documentation, contact [waishnav@gitcms.dev](mailto:waishnav@gitcms.dev) about complimentary access.

Complimentary access is handled manually and is not part of a public self-serve free plan.
