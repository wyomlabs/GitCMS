## How to edit a README

1. Paste a public repository, such as `vercel/next.js`, or a link to its README.
2. GitCMS opens the repository with the README in a visual editor.
3. Edit the file, then copy the full Markdown or export a patch and apply it with `git apply`.

## Frequently asked questions

### Do I need to sign in?

No. Public repositories open without an account. To save changes back to your own repository as commits, connect it to [GitCMS](/).

### Does it work with private repositories?

Private repositories need a GitCMS workspace with the GitHub App installed on the repository.
