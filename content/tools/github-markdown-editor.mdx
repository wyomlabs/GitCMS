## How it works

1. Paste a public GitHub URL, such as a repository, folder, or file link, or type `owner/repo`.
2. GitCMS opens the repository and lists its Markdown and MDX files.
3. Edit a file in the visual editor, then copy the full file or export a patch to apply locally.

GitHub links work too: replace `github.com` with `app.gitcms.dev` in any repository URL to open it directly.

## Frequently asked questions

### Which files can I edit?

Markdown (`.md`) and MDX (`.mdx`) files, including frontmatter.

### Can I save changes back to GitHub?

Connect the repository to [GitCMS](/) to save edits as commits, either directly to your default branch or through review before publish.
