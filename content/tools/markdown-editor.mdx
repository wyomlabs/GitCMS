## How to use the editor

1. Fill in the **title** and **description** fields. They become YAML frontmatter at the top of the file.
2. Write in the editor body. Type `/` for headings, lists, quotes, tables, and code blocks, or use Markdown shortcuts such as `##` and `-`.
3. Select **Copy Markdown** to paste the file somewhere else, or **Download** to save `document.md`.

## Who it's for

The editor is for anyone who needs a clean Markdown file without setting up a local toolchain: blog posts for Astro, Next.js, Hugo, or Jekyll sites, documentation pages, and notes you plan to commit to a repository.

## Frequently asked questions

### Does it upload my writing?

No. The editor runs in your browser. Nothing is saved to a server, so copy or download your file before you close the tab.

### What frontmatter does it produce?

A YAML block with `title` and `description`. Most static site generators read these fields for the page title and meta description.

### Can I edit Markdown files that are already in my repository?

Not here. This free tool starts from a blank file. [GitCMS](/) opens the Markdown and MDX files in your GitHub repository in the same editor and saves every change as a commit.
